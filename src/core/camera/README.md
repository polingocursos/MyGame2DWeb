# 📷 CAMERA SYSTEM

Sistema de câmera que segue o player.

## Implementação
Usa `pixi-viewport` ou câmera manual movendo o container `world`.

## Funcionalidades planejadas
- Seguir player suavemente (lerp)
- Limitar aos bounds do mapa
- Shake de câmera (impacto, explosão)
- Zoom suave em eventos especiais

## Arquivo principal
`CameraSystem.js`
