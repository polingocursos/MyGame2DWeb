# 🧱 PLATAFORMAS

Imagens usadas como plataformas onde o player anda.

## Subpastas
- `ground/` — chão principal (tile horizontal)
- `floating/` — plataformas flutuantes isoladas
- `special/` — plataformas com efeitos (gelo, fogo, etc.)

## Dicas
- Definir hitbox separadamente no código (não pelo tamanho visual)
- Tiles de plataforma devem ser tileáveis horizontalmente
