# 🗺️ MAPAS

## Subpastas
- `tilesets/` — tiles PNG e dados JSON (para Tiled)
- `levels/` — arquivos .tmj/.json de cada fase (exportados do Tiled)
- `minimap/` — imagens de minimapa por fase

## Ferramenta recomendada
[Tiled Map Editor](https://www.mapeditor.org/) — gratuito e exporta JSON
Plugin PixiJS: `pixi-tiled` ou `@pixi/tilemap`
