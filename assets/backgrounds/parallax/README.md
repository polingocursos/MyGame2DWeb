# 🏔️ PARALLAX LAYERS

Camadas de parallax para criar profundidade.

## Estrutura sugerida
- `far/` — camada mais longe (scroll 0.1x)
- `mid/` — camada média (scroll 0.4x)
- `near/` — camada mais próxima (scroll 0.7x)

## Dicas
- Imagens devem ser tileadas horizontalmente
- Fundo transparente (PNG) para sobrepor camadas
