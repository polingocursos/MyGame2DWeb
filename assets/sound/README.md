# 🔊 SONS

## Estrutura
- `music/lobby/` — música da tela inicial (loop suave)
- `music/gameplay/` — música das fases
- `music/boss/` — música de boss
- `sfx/player/` — sons do player (pulo, ataque, hurt)
- `sfx/enemies/` — sons de inimigos
- `sfx/items/` — sons de coleta e uso de item
- `sfx/ui/` — cliques, hover, confirmação
- `sfx/environment/` — vento, água, fogo
- `ambient/` — sons ambiente (floresta, caverna, etc.)

## Formatos
- MP3 para música (compressão boa)
- OGG ou MP3 para SFX
