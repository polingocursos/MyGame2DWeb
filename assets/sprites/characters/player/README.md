# 🧑 SPRITES DO PLAYER

Coloque aqui as spritesheets do personagem jogável.

## Formato recomendado
- Spritesheet em PNG + JSON (TexturePacker / Aseprite)
- Nomeação: `player_idle_01.png`, `player_run_01.png`, etc.

## Animações necessárias
- `idle` — parado (4-6 frames)
- `run` — correndo (8 frames)
- `jump` — subindo (4 frames)
- `fall` — caindo (4 frames)
- `attack` — ataque (6-8 frames)
- `hurt` — tomando dano (3 frames)
- `death` — morrendo (6 frames)
