# 💰 DATA — ECONOMIA

Arquivos JSON com dados do sistema econômico.

## Arquivos planejados
- `currencies.json` — tipos de moeda e suas propriedades
- `shop.json` — itens disponíveis na loja e preços
- `rewards.json` — recompensas por ações (matar inimigo, quest, etc.)
- `drop_tables.json` — tabela de drops de inimigos
